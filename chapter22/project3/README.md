# Same-number subsequence

Write an O(n) time program that prompts the user to enter a sequence of integers ending with 0 and finds the longest subsequence with the same number.

## Sample Run

    Enter a series of numbers ending with 0: 2 4 4 8 8 8 8 2 4 4 0
    The longest same number sequence starts at index 3 with 4 values of 8
